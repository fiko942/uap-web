# Golden Dragon Wok - Frontend

This is the frontend for the Golden Dragon Wok Restaurant Dashboard.

## Tech Stack
- React
- Vite
- Tailwind CSS
- React Router DOM

## Getting Started

1. `npm install`
2. `npm run dev`
